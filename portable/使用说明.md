# 完全卸载面板 · 便携版（Windows 通用）

## 先回答你的问题

|           | 之前的版本（`uninstall-panel/`）                                                                                                                         | 这个便携版                                   |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| 形态        | `index.html` + `server.py` + `start-panel.bat`                                                                                                    | **单个 `UninstallPanel.ps1`**（界面已内嵌）      |
| 拿到别的电脑能用吗 | ❌ **不能直接用**。那个 `index.html` 只是个"壳"，所有数据（软件清单、卸载命令、残留扫描）都要向 `server.py` 要；而目标电脑必须装有 **Python 3**，`start-panel.bat` 里还写死了 `C:\Python314\python.exe` | ✅ **能**。只用 Windows 自带的 PowerShell，零外部依赖 |
| 依赖        | Python 3 + PowerShell + 管理员权限                                                                                                                     | 仅 PowerShell（Windows 自带）+ 管理员权限         |
| 界面        | 同一套界面                                                                                                                                             | **同一套界面**，原封不动内嵌进脚本                     |

一句话：**那个 HTML 单独拷到别的电脑上只会打开一个报错的空白页**（`/api/state` 取不到数据）。  
本版把「引擎 + 界面」合并成一个 `.ps1`，拷过去双击即可用。

> 顺带说明：脚本里的「风险规则库」「残留路径知识库」都是**通用知识**（对微信、WPS、Chrome、网银、驱动等的判断），不是本机专属数据，换电脑一样有效。

## 使用方法

1. 把 `UninstallPanel.ps1` 和 `启动面板.bat` 放在**同一个目录**（U 盘 / 微信传文件 / 任意位置都行）
2. 双击 **`启动面板.bat`** → 自动请求管理员权限 → 浏览器自动打开面板
3. 用完**关闭那个黑窗口**即可停止面板

也可以完全不用 `.bat`，直接命令行运行：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\UninstallPanel.ps1
```

## 参数

| 参数                  | 说明                                                |
| ------------------- | ------------------------------------------------- |
| `-Port 8800`        | 指定端口。默认 8791，被占用时自动往后找空闲端口                        |
| `-WorkDir D:\panel` | 指定数据目录。默认 `%LOCALAPPDATA%\UninstallPanel`         |
| `-NoBrowser`        | 不自动打开浏览器                                          |
| `-NoElevate`        | 不尝试提权，以当前权限运行                                     |
| `-SelfTest`         | 自检模式：通过真实接口跑一遍全链路，**引擎被强制降级为"演练"，物理上不会执行任何卸载或删除** |

> **关于自检模式**：它会顺序验证「首页加载 → 软件清单 → 体积统计 → 命令预览 → 安全护栏 → 系统备份 → 卸载作业流水线（演练）→ 注册表快照往返 → 残留隔离/还原往返 → 残留扫描 → 快照列表 → 关闭服务」，结果写入 `%LOCALAPPDATA%\UninstallPanel\selftest.txt`。  
> 自检期间引擎处于 `dryrun` 硬保护状态：任何卸载请求都会被改写成"只走流程、不碰系统"，因此可以放心运行。

## 对其它电脑的兼容性

- **需要**：Windows 7 SP1 及以上；PowerShell 系统自带，无需安装任何东西
- **Windows 10 / 11**：全部功能（含商店应用 AppX 清理）
- **Windows 7 / 8.1**：桌面程序全部可用；"商店应用"部分自动跳过（旧系统没有 AppX）
- **管理员权限**：卸载、残留清理、创建系统还原点需要管理员。脚本会自己请求提权，也可以手动右键"以管理员身份运行"
- **为什么必须用 `.bat` 或 `-ExecutionPolicy Bypass`**：Windows 默认禁止直接运行 `.ps1`（脚本执行策略，微软默认安全设置）。所以双击 `.ps1` 通常会用记事本打开而不是运行——这是正常的，用 `.bat` 启动即可

## 数据目录

默认 `%LOCALAPPDATA%\UninstallPanel\`：

- `backups\` — 注册表快照（JSON，可一键写回）、`last_backup.json`
- `quarantine\` — 隔离区（从原位置**移动**过来的残留，可还原）+ `manifest.json`
- `jobs\` — 每次卸载作业的输入与逐行日志
- `panel.info.json` — 本次运行信息（端口 / 地址 / PID）
- `selftest.txt` — 自检报告

## 安全模型（四道护栏）

1. **预览**：执行前先看要跑的**确切命令行**，可逐条改写，也可切换「静默 / 交互」模式
2. **备份**：创建系统还原点 + 注册表卸载项快照（系统保护没开时会自动开启；失败会明确告知原因）
3. **二次确认**：必须手工输入"确认卸载"；**未备份不允许卸载**；单批上限 10 项
4. **可逆**：残留是**移动进隔离区**而不是删除；注册表项先落 JSON 快照再删；确认无用后送**回收站**（回收站里仍可恢复）

## 界面功能一览

- 软件清单：注册表卸载项（HKLM 64/32 + HKCU）+ 商店应用，可搜索 / 按体积或日期排序 / 按风险筛选
- 每个软件标注 **安全 / 谨慎 / 高风险** 与中文原因（默认按占用体积排序）
- 卸载方式自动识别：MSI → `msiexec /x`；EXE → 厂商静默参数（Inno `/VERYSILENT`、NSIS `/S`）；商店应用 → `Remove-AppxPackage`
- 残留扫描：Program Files / ProgramData / AppData / 注册表的候选残留，逐项标注可信度；疑似属于其它软件的项自动降级为"低可信"且**默认不勾选**
- 隔离区：按批次还原文件、写回注册表快照、送回收站
